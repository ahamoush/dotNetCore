شرح ProjectsController

CRUD للمشاريع مع سياسة صلاحية لكل عملية

الغرض

الكلاس محمي بـ [Authorize] على مستوى الـ Controller؛ كل Action يضيف [Authorize(Policy = AppPermissions.Projects.*)].

JWT ← Policy ← IProjectService ← استجابة

تحقق الإنشاء والتحديث

[Authorize(Policy = AppPermissions.Projects.Create)]
[HttpPost]
public async Task<IActionResult> Create(CreateProjectDto dto)
{
    IActionResult? invalid = await InputValidation.CheckAsync(_createValidator, dto, ...);
    if (invalid is not null) return invalid;
    ProjectResponseDto project = await _service.CreateAsync(dto);
    return Ok(project);
}
بدون دور يملك السياسة، UseAuthorization يرجع 403 قبل الوصول للخدمة.
