شرح InputValidation

جسر FluentValidation إلى ValidationProblemDetails

الغرض

كلاس ثابت InputValidation يوحّد شكل أخطاء التحقق من المدخلات في الـ API.

ValidateAsync ← تجميع الأخطاء ← BadRequest 400

CheckAsync

public static async Task<IActionResult?> CheckAsync<T>(
    IValidator<T> validator,
    T model,
    CancellationToken cancellationToken)
{
    ValidationResult result = await validator.ValidateAsync(model, cancellationToken);
    if (result.IsValid)
        return null;
    // ...
    problem.Status = StatusCodes.Status400BadRequest;
    problem.Title = "One or more validation errors occurred.";
    return new BadRequestObjectResult(problem);
}

الأخطاء مجمّعة حسب PropertyName في قاموس داخل ValidationProblemDetails.

استخدام من Controllers

IActionResult? invalid = await InputValidation.CheckAsync(_loginValidator, dto, HttpContext.RequestAborted);
if (invalid is not null)
    return invalid;
الـ Validators تُسجّل في AddApplication() عبر AddValidatorsFromAssembly.
