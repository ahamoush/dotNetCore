شرح appsettings.Development.json

JWT، زرع SuperAdmin، وسجلات تطوير — قيم حساسة مُستبدلة بـ placeholders

الغرض

يُطبَّق عند ASPNETCORE_ENVIRONMENT=Development (انظر launchSettings.json.html).

الشكل التوضيحي (مُنقَّح)

{
  "Jwt": {
    "Key": "<مفتاح-JWT-سري-32+ حرف>",
    "Issuer": "ProjectManagementSystem",
    "Audience": "ProjectManagementSystem",
    "ExpiresInMinutes": 60
  },
  "Seed": {
    "SuperAdmin": {
      "Email": "<بريد-المدير>",
      "Password": "<كلمة-سر-قوية>",
      "FullName": "Super Admin"
    }
  },
  "Logging": {
    "LogLevel": {
      "Default": "Debug",
      "Microsoft.AspNetCore": "Information"
    }
  }
}
الملف المصدري يحتوي قيماً فعلية للتطوير؛ لا تُنسخ إلى وثائق عامة ولا إلى git عام دون تدوير الأسرار.

جدول المفاتيح

المقطعمستوى السجل / ملاحظةأين يُستخدم
Jwt:Key—Program.cs — يفشل الإقلاع إن كان null
Jwt:Issuer / Audience—TokenValidationParameters وإنشاء التوكن
Jwt:ExpiresInMinutes60 في الملفخدمة المصادقة
Seed:SuperAdmin:*—IdentitySeeder.SeedSuperAdminAsync
Logging:DefaultDebugسجلات أوضح في التطوير
Logging:Microsoft.AspNetCoreInformationتفاصيل أكثر عن pipeline
