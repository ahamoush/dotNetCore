شرح ملف AppRoles.cs خطوة بخطوة

أسماء الأدوار الثابتة في النظام ومصفوفة All للمراجعة والبذر

قبل أن نبدأ: ما وظيفة هذا الملف؟

كلاس ثابت يعرّف أسماء الأدوار كنصوص ثابتة (const string) حتى لا تُكتَب الأسماء يدوياً في أماكن متعددة. مصفوفة All تجمع كل الأدوار للاستخدام في التحقق أو تهيئة قاعدة البيانات.

دور في JWT / Identity → AppRoles.* → RolePermissionMap

1) تعريف الأدوار

public static class AppRoles
{
    public const string SuperAdmin = "SuperAdmin";
    public const string Admin = "Admin";
    public const string ProjectManager = "ProjectManager";
    public const string TeamLeader = "TeamLeader";
    public const string Member = "Member";
    public const string Viewer = "Viewer";

    public static readonly string[] All =
    [
        SuperAdmin,
        Admin,
        ProjectManager,
        TeamLeader,
        Member,
        Viewer
    ];
}
الثابتقيمة النصدور تقريبي
SuperAdminSuperAdminأعلى مستوى — في الخريطة يحصل على كل الصلاحيات.
AdminAdminإدارة كاملة للصلاحيات المعرفة في AppPermissions.All.
ProjectManagerProjectManagerإدارة مشاريع ومهام بحدود محددة في الخريطة.
TeamLeaderTeamLeaderمهام بصلاحيات أوسع من العضو.
MemberMemberعرض وتحديث مهام محدود.
ViewerViewerعرض فقط للمشاريع والمهام.

خلاصة تحفظها

  • ستة أدوار مرتبة من الأعلى صلاحية إلى الأدنى تقريباً.
  • استخدم الثوابت بدل كتابة "Admin" مباشرة في الكود.
  • All مصدر واحد لقائمة الأدوار الكاملة.
