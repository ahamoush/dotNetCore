2) EnsureEveryPermissionHasARole

public static void EnsureEveryPermissionHasARole()
{
    var missing = new List<string>();
    foreach (string permission in AppPermissions.All)
    {
        if (RolesWith(permission).Length == 0)
            missing.Add(permission);
    }

    if (missing.Count > 0)
    {
        throw new InvalidOperationException(
            "Permissions are not assigned to any role: " + string.Join(", ", missing));
    }
}

يمر على كل صلاحية معرّفة في All. إن لم يجد أي دور يحملها عبر RolesWith، يرمي InvalidOperationException عند التشغيل — حماية من صلاحية «يتيمة» لا يمكن لأحد استخدامها.

3) ForRole

public static IReadOnlyList<string> ForRole(string role)
{
    if (Map.TryGetValue(role, out string[]? permissions))
        return permissions;

    return [];
}

دور معروف يُرجع مصفوفته. دور غير موجود في القاموس يُرجع قائمة فارغة (وليس null).

4) ForRoles — دمج بدون تكرار

public static IReadOnlyList<string> ForRoles(IEnumerable<string> roles)
{
    var permissions = new List<string>();
    foreach (string role in roles)
    {
        foreach (string permission in ForRole(role))
        {
            if (!permissions.Contains(permission))
                permissions.Add(permission);
        }
    }

    return permissions;
}

مستخدم له أكثر من دور يحصل على اتحاد الصلاحيات دون تكرار نفس النص.

5) RolesWith — عكس الخريطة

public static string[] RolesWith(string permission)
{
    var roles = new List<string>();
    foreach (KeyValuePair<string, string[]> pair in Map)
    {
        foreach (string allowed in pair.Value)
        {
            if (allowed == permission)
            {
                roles.Add(pair.Key);
                break;
            }
        }
    }

    return roles.ToArray();
}

يعيد أسماء الأدوار التي تتضمن صلاحية معينة — يُستخدم داخل EnsureEveryPermissionHasARole.

خلاصة تحفظها

  • مصدر الحقيقة لربط الأدوار بالصلاحيات في طبقة Application.
  • ForRoles للمستخدم متعدد الأدوار؛ ForRole لدور واحد.
  • EnsureEveryPermissionHasARole يضمن تغطية كاملة لـ AppPermissions.All.
