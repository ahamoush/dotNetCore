شرح ملف DependencyInjection.cs خطوة بخطوة

كيف تُسجَّل مُحققون وAutoMapper وخدمات المشاريع والمهام في حاوية DI

قبل أن نبدأ: ما وظيفة هذا الملف؟

كلاس ثابت DependencyInjection يوفّر امتدادين لـ ASP.NET Core: AddApplication لتسجيل كل ما تحتاجه طبقة Application عند تشغيل الـ API، وAssertMappingsAreValid للتحقق من صحة تعيينات AutoMapper بعد بناء التطبيق.

Program.cs يستدعي AddApplication ← Validators + AutoMapper ← ProjectService / TaskService

1) الاستيرادات

using AutoMapper;
using FluentValidation;
using Microsoft.Extensions.DependencyInjection;
using ProjectManagementSystem.Application.Interfaces;
using ProjectManagementSystem.Application.Services;

AutoMapper وFluentValidation للتسجيل التلقائي، وIServiceCollection من حزمة Abstractions، والواجهات مع تنفيذات الخدمات.

2) الدالة AddApplication

public static IServiceCollection AddApplication(this IServiceCollection services)
{
    services.AddValidatorsFromAssembly(typeof(DependencyInjection).Assembly);
    services.AddAutoMapper(_ => { }, typeof(DependencyInjection));

    services.AddScoped<IProjectService, ProjectService>();
    services.AddScoped<ITaskService, TaskService>();
    return services;
}
السطرماذا يفعل؟
AddValidatorsFromAssembly(...)يفحص مجمّع هذا المشروع ويسجّل كل كلاس يطبّق IValidator<T> (مجلد Validators).
AddAutoMapper(..., typeof(DependencyInjection))يسجّل AutoMapper ويجد ملفات Profile مثل MappingProfile في نفس المجمّع.
AddScoped<IProjectService, ProjectService>عند كل طلب HTTP يُنشأ ProjectService واحد ويُحقَن في الـ Controller.
AddScoped<ITaskService, TaskService>نفس نمط العمر Scoped لخدمة المهام.
ملاحظة: هذا الملف لا يسجّل IAuthService أو IUserAdminService — تسجيلهما إن وُجد يكون في طبقة أخرى (مثل Infrastructure أو Api).

3) الدالة AssertMappingsAreValid

public static void AssertMappingsAreValid(this IServiceProvider services)
{
    services.GetRequiredService<IConfigurationProvider>().AssertConfigurationIsValid();
}

يُستدعى بعد بناء التطبيق (غالباً من Program.cs). إذا كان أي CreateMap ناقصاً أو غير متسق، يرمي استثناءً عند التشغيل بدل خطأ غامض أثناء الطلب.

خلاصة تحفظها

  • AddApplication = Validators + AutoMapper + ProjectService + TaskService.
  • الخدمات Scoped — مناسبة لطلب ويب واحد.
  • AssertMappingsAreValid يفحص تعيينات AutoMapper مبكراً.
