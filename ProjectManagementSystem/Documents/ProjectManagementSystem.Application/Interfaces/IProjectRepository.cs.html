الواجهة في طبقة Application لكنها تتعامل مع كيان Project من Domain. كلاس EF في Infrastructure يطبّقها. ProjectService لا يستخدم DbContext مباشرة بل هذه الواجهة.

ProjectService → IProjectRepository → تنفيذ Infrastructure

1) الأعضاء

public interface IProjectRepository
{
    Task<List<Project>> ListAsync();

    Task<Project?> GetByIdAsync(int id, bool tracking);

    Task AddAsync(Project project);

    Task<bool> AnyAsync(int id);

    Task<(List<Project> Items, int TotalCount)> SearchAsync(ProjectQueryDto query);

    Task SaveChangesAsync();
}
الدالةالاستخدام في ProjectService
ListAsyncGetAllAsync
GetByIdAsync(id, tracking)false للقراءة؛ true للتحديث والحذف المنطقي
AddAsync + SaveChangesAsyncCreateAsync
AnyAsyncيُستدعى من TaskService.CreateAsync للتحقق من وجود المشروع
SearchAsyncGetProjectsAsync — ترقيم + عدد إجمالي
معامل tracking يحدد هل EF يتتبع التغييرات على الكيان — ضروري قبل SaveChangesAsync عند التحديث.

خلاصة تحفظها

  • لا DTOs هنا — كيانات Domain فقط.
  • SearchAsync يعيد tuple (عناصر، العدد الكلي) للصفحات.
