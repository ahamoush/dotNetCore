عقد إدارة مستخدمين (عرض، أدوار، تعيين أدوار). يمرّر معرف المستخدم المنفِّذ وما إذا كان SuperAdmin لفرض قواعد أمان داخل التنفيذ.

1) التوقيعات

public interface IUserAdminService
{
    Task<IReadOnlyList<UserResponseDto>> GetUsersAsync();

    IReadOnlyList<RoleResponseDto> GetRoles();

    Task<UserAdminResult> SetRolesAsync(
        string userId,
        IReadOnlyList<string> roles,
        string actorUserId,
        bool actorIsSuperAdmin);
}
الدالةالوصف
GetUsersAsyncيجلب كل المستخدمين كـ UserResponseDto.
GetRolesمتزامنة (ليست async) — تعيد قائمة أدوار للواجهة، غالباً من AppRoles في التنفيذ.
SetRolesAsyncيحدّث أدوار userId. actorUserId وactorIsSuperAdmin لمنع تعيين أدوار خطرة دون صلاحية.

خلاصة تحفظها

  • مرتبط بصلاحية Permissions.Users.* في Api.
  • غير مسجّل في AddApplication — مثل IAuthService.
