شرح ملف المشروع خطوة بخطوة

بطاقة مشروع Class Library لطبقة Application — خدمات، DTOs، مُحققون، ولا DbContext هنا

قبل أن نبدأ: ما وظيفة هذا الملف؟

ملف csproj يعرّف مشروع مكتبة صنفية (Class Library) اسمها ProjectManagementSystem.Application. هذه الطبقة تحتوي منطق التطبيق: خدمات المشاريع والمهام، كائنات نقل البيانات (DTOs)، قواعد FluentValidation، تعيينات AutoMapper، وتعريفات الأدوار والصلاحيات. لا تحتوي على DbContext ولا على Controllers — ذلك في طبقات أخرى.

Domain (كيانات) ← Application (هذا المشروع) ← Infrastructure / Api

1) محتوى الملف كما في المستودع

<Project Sdk="Microsoft.NET.Sdk">

  <ItemGroup>
    <ProjectReference Include="..\ProjectManagementSystem.Domain\ProjectManagementSystem.Domain.csproj" />
  </ItemGroup>

  <ItemGroup>
    <PackageReference Include="AutoMapper" Version="17.0.0" />
    <PackageReference Include="FluentValidation" Version="12.2.0" />
    <PackageReference Include="FluentValidation.DependencyInjectionExtensions" Version="12.2.0" />
    <PackageReference Include="Microsoft.Extensions.DependencyInjection.Abstractions" Version="10.0.14" />
  </ItemGroup>

  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
  </PropertyGroup>

</Project>

2) مرجع المشروع (ProjectReference)

العنصرالمعنى
ProjectManagementSystem.Domainالمرجع الوحيد بين المشاريع. طبقة Application تعتمد على كيانات Domain مثل Project وProjectTask، ولا تشير إلى Infrastructure أو Api.
Clean Architecture: الاعتماد يتجه نحو الداخل (Domain). تطبيق الويب يستهلك Application، وليس العكس.

3) الحزم (PackageReference)

الحزمةالدور في هذا المشروع
AutoMapper 17.0.0تحويل بين كيانات Domain و DTOs عبر MappingProfile.
FluentValidation 12.2.0كتابة مُحققين لـ DTOs في مجلد Validators.
FluentValidation.DependencyInjectionExtensionsتوفّر AddValidatorsFromAssembly المستخدمة في DependencyInjection.cs.
Microsoft.Extensions.DependencyInjection.Abstractionsيسمح بتعريف امتداد AddApplication على IServiceCollection دون الاعتماد على مشروع ويب كامل.

4) إعدادات البناء

الخاصيةالقيمةالتأثير
TargetFrameworknet10.0المشروع يستهدف .NET 10.
ImplicitUsingsenableاستيرادات شائعة تُضاف تلقائياً (مثل System).
Nullableenableتحذيرات للمراجع التي قد تكون null — مهم في واجهات مثل GetByIdAsync التي ترجع ?.

5) ماذا يوجد داخل المشروع (من هيكل المجلدات)؟

  • Services — تنفيذ ProjectService وTaskService.
  • Interfaces — عقود الخدمات والمستودعات.
  • DTOs — نماذج الإدخال والإخراج للـ API.
  • Validators — قواعد التحقق قبل تنفيذ المنطق.
  • Mapping — MappingProfile لـ AutoMapper.
  • Authorization — أدوار، صلاحيات، Claims، وخريطة الربط.
  • DependencyInjection.cs — تسجيل الخدمات في الحاوية.

خلاصة تحفظها

  • مكتبة وليست تطبيق ويب — لا DbContext ولا Controllers هنا.
  • مرجع واحد: Domain فقط.
  • AutoMapper + FluentValidation + DI Abstractions هي الاعتمادات الخارجية الرئيسية.
