شرح ملف ProjectService.cs خطوة بخطوة

تنفيذ IProjectService: مستودع + AutoMapper، حذف منطقي، واستعلام مرقّم

قبل أن نبدأ: ما وظيفة هذا الملف؟

كلاس ProjectService يطبّق منطق الأعمال للمشاريع. يعتمد على IProjectRepository للوصول للبيانات وIMapper للتحويل بين Project و DTOs. لا يتحدث مع قاعدة البيانات مباشرة.

DTO → Map → Project → Repository → SaveChanges → Map → ResponseDto

1) الحقن في المُنشئ

public ProjectService(IProjectRepository projects, IMapper mapper)
{
    _projects = projects;
    _mapper = mapper;
}

ASP.NET Core يوفّر المستودع والـ Mapper تلقائياً لأنها مسجّلة في DI.

2) GetAllAsync

public async Task<IEnumerable<ProjectResponseDto>> GetAllAsync()
{
    var projects = await _projects.ListAsync();
    return _mapper.Map<List<ProjectResponseDto>>(projects);
}
  • يستدعي ListAsync ثم يحوّل القائمة كاملة إلى DTOs.

3) GetByIdAsync

public async Task<ProjectResponseDto?> GetByIdAsync(int id)
{
    var project = await _projects.GetByIdAsync(id, tracking: false);
    return project is null ? null : _mapper.Map<ProjectResponseDto>(project);
}
  • tracking: false للقراءة فقط — أخف على EF.
  • إن لم يُوجد المشروع يُرجع null وليس استثناءً.

4) CreateAsync

public async Task<ProjectResponseDto> CreateAsync(CreateProjectDto dto)
{
    var project = _mapper.Map<Project>(dto);

    await _projects.AddAsync(project);
    await _projects.SaveChangesAsync();

    return _mapper.Map<ProjectResponseDto>(project);
}
Map DTO ← AddAsync ← SaveChangesAsync ← إرجاع DTO (مع Id بعد الحفظ)

5) UpdateAsync

public async Task<bool> UpdateAsync(int id, UpdateProjectDto dto)
{
    var project = await _projects.GetByIdAsync(id, tracking: true);
    if (project is null)
        return false;

    _mapper.Map(dto, project);
    project.UpdatedAt = DateTime.UtcNow;

    await _projects.SaveChangesAsync();
    return true;
}
  • tracking: true لأن الخصائص تُعدَّل على الكيان المحمّل.
  • _mapper.Map(dto, project) يحدّث الحقول الموجودة من DTO.
  • يضبط UpdatedAt يدوياً بـ UTC.

6) DeleteAsync — حذف منطقي

public async Task<bool> DeleteAsync(int id)
{
    var project = await _projects.GetByIdAsync(id, tracking: true);
    if (project is null)
        return false;

    project.IsDeleted = true;
    project.DeletedAt = DateTime.UtcNow;

    await _projects.SaveChangesAsync();
    return true;
}
لا يستدعي Remove — الصف يبقى في القاعدة مع IsDeleted = true. فلترة المحذوفين تكون في طبقة Infrastructure عند القراءة.

7) GetProjectsAsync — ترقيم صفحات

public async Task<PagedResultDto<ProjectResponseDto>> GetProjectsAsync(ProjectQueryDto query)
{
    var (items, totalCount) = await _projects.SearchAsync(query);

    return new PagedResultDto<ProjectResponseDto>
    {
        Items = _mapper.Map<List<ProjectResponseDto>>(items),
        TotalCount = totalCount,
        PageNumber = query.PageNumber,
        PageSize = query.PageSize
    };
}
  • البحث والعدّ الإجمالي في المستودع عبر SearchAsync.
  • يعيد Items للصفحة الحالية وTotalCount لكل النتائج المطابقة.

خلاصة تحفظها

  • كل العمليات async وتمر عبر المستودع.
  • الحذف soft delete؛ التحديث يحدّث UpdatedAt.
  • الترقيم فقط في GetProjectsAsync.
