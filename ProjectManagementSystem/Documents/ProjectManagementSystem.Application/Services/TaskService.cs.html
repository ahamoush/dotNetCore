شرح ملف TaskService.cs خطوة بخطوة

مهام مرتبطة بمشاريع: تحقق من وجود المشروع، حذف فيزيائي للمهمة

قبل أن نبدأ: ما وظيفة هذا الملف؟

تنفيذ ITaskService. يستخدم مستودعين: ITaskRepository للمهام وIProjectRepository للتحقق أن ProjectId موجود قبل الإنشاء.

Create → AnyAsync(ProjectId) → AddAsync → SaveChanges

1) المُنشئ — ثلاث اعتماديات

public TaskService(ITaskRepository tasks, IProjectRepository projects, IMapper mapper)
{
    _tasks = tasks;
    _projects = projects;
    _mapper = mapper;
}

2) GetAllAsync

public async Task<IEnumerable<TaskResponseDto>> GetAllAsync(int? projectId)
{
    var tasks = await _tasks.ListAsync(projectId);
    return _mapper.Map<List<TaskResponseDto>>(tasks);
}

يمرّر projectId كما هو للمستودع — تصفية اختيارية حسب المشروع.

3) GetByIdAsync

public async Task<TaskResponseDto?> GetByIdAsync(int id)
{
    var task = await _tasks.GetByIdAsync(id, tracking: false);
    return task is null ? null : _mapper.Map<TaskResponseDto>(task);
}

4) CreateAsync — فشل صامت إن لم يوجد المشروع

public async Task<TaskResponseDto?> CreateAsync(CreateTaskDto dto)
{
    if (!await _projects.AnyAsync(dto.ProjectId))
        return null;

    var task = _mapper.Map<ProjectTask>(dto);

    await _tasks.AddAsync(task);
    await _tasks.SaveChangesAsync();

    return _mapper.Map<TaskResponseDto>(task);
}
لا يرمي استثناءً عند مشروع غير موجود — يُرجع null ويترك للـ Controller اختيار رمز HTTP (مثل 404 أو 400).

5) UpdateAsync

public async Task<bool> UpdateAsync(int id, UpdateTaskDto dto)
{
    var task = await _tasks.GetByIdAsync(id, tracking: true);
    if (task is null)
        return false;

    _mapper.Map(dto, task);

    await _tasks.SaveChangesAsync();
    return true;
}

لا يحدّث UpdatedAt هنا (على عكس ProjectService) — فقط تعيين من DTO.

6) DeleteAsync — حذف فيزيائي

public async Task<bool> DeleteAsync(int id)
{
    var task = await _tasks.GetByIdAsync(id, tracking: true);
    if (task is null)
        return false;

    _tasks.Remove(task);
    await _tasks.SaveChangesAsync();
    return true;
}
يستخدم Remove وليس علامة حذف منطقي — يختلف عن حذف المشاريع في ProjectService.

خلاصة تحفظها

  • إنشاء مهمة يتطلب مشروعاً موجوداً عبر AnyAsync.
  • لا استعلام مرقّم للمهام في هذه الخدمة.
  • حذف المهمة يزيل السجل من قاعدة البيانات.
