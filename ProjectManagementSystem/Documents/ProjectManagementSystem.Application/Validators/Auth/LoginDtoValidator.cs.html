شرح الملف خطوة بخطوة

التحقق من بيانات تسجيل الدخول قبل الخدمة.

ما هو هذا النوع؟

FluentValidation يتحقق من صحة LoginDto قبل أن تصل البيانات إلى خدمة المصادقة.

طلب HTTP ← ربط JSON بـ LoginDto ← LoginDtoValidator ← الخدمة

الكود في المشروع

using FluentValidation;
using ProjectManagementSystem.Application.DTOs.Auth;

namespace ProjectManagementSystem.Application.Validators.Auth;

public sealed class LoginDtoValidator : AbstractValidator<LoginDto>
{
    public LoginDtoValidator()
    {
        RuleFor(x => x.Email)
            .NotEmpty()
            .EmailAddress()
            .MaximumLength(256);

        RuleFor(x => x.Password)
            .NotEmpty()
            .MaximumLength(100);
    }
}

المسار: Validators/Auth/LoginDtoValidator.cs

قواعد التحقق

الحقلالقواعد
EmailNotEmpty، EmailAddress، MaximumLength(256)
PasswordNotEmpty، MaximumLength(100)
متى يُشغَّل؟ عند تفعيل التحقق التلقائي في ASP.NET Core مع FluentValidation؛ إذا فشل التحقق يُعاد خطأ دون استدعاء الخدمة.

ملخص

مدقق مختوم (sealed) يرث AbstractValidator<LoginDto> ويضبط قواعد البريد وكلمة المرور كما في الملف.
