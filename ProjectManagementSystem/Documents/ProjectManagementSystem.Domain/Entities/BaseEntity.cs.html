شرح ملف BaseEntity.cs خطوة بخطوة

دليل للمبتدئ: ما هي الخصائص المشتركة بين الكيانات؟ وكيف يعمل الحذف الناعم Soft Delete؟

قبل أن نبدأ: ما وظيفة هذا الملف؟

يُعرّف هذا الملف صنفاً أساسياً abstract اسمه BaseEntity داخل طبقة Domain. الكيانات الأخرى مثل Project ترث منه لتحصل على نفس الحقول: المعرف، تواريخ الإنشاء والتحديث، وعلامات الحذف الناعم. الملف لا يحتوي منطق قاعدة بيانات ولا استعلامات؛ هو مجرد شكل بيانات مشترك.

إنشاء سجل ← تعيين CreatedAt ← تحديث UpdatedAt ← حذف ناعم: IsDeleted + DeletedAt

1) مساحة الأسماء والصنف الأساسي

namespace ProjectManagementSystem.Domain.Entities;

// خصائص مشتركة بين الجداول (Id + تواريخ + Soft Delete)
public abstract class BaseEntity
{
  • namespace ProjectManagementSystem.Domain.Entities: يضع الأنواع في مساحة أسماء الكيانات ضمن مشروع Domain.
  • التعليق العربي يوضح نية الملف: خصائص مشتركة بين الجداول.
  • public abstract class BaseEntity: صنف عام لكنه مجرد؛ لا يمكن إنشاء كائن منه مباشرة، بل يُورَّث فقط.
لماذا abstract؟ ليجبر المصمم على استخدام صنف فرعي (مثل Project) يمثل كياناً حقيقياً في النموذج، مع الاحتفاظ بالحقول المشتركة في مكان واحد.

2) خصائص الهوية والزمن

    public int Id { get; set; }

    public DateTime CreatedAt { get; set; } = DateTime.UtcNow;

    public DateTime? UpdatedAt { get; set; }
الخاصيةالنوعالمعنى في الكود
Idintمعرف رقمي للسجل. في هذا الملف لا يُحدد كيف يُولَّد؛ ذلك يقع عادة في طبقة التخزين.
CreatedAtDateTimeوقت الإنشاء. القيمة الافتراضية عند إنشاء الكائن في الذاكرة هي DateTime.UtcNow (توقيت UTC).
UpdatedAtDateTime?وقت آخر تحديث إن وُجد. علامة ? تعني أن القيمة قد تكون null إذا لم يُحدَّث السجل بعد.
استخدام UtcNow يقلل لبس المناطق الزمنية عند حفظ التواريخ في قاعدة بيانات أو عرضها لاحقاً من طبقات أخرى.

3) حقول الحذف الناعم (Soft Delete)

    public bool IsDeleted { get; set; } = false;

    public DateTime? DeletedAt { get; set; }
}
الخاصيةالقيمة الافتراضيةالدور
IsDeletedfalseعلامة منطقية: هل اعتُبر السجل محذوفاً منطقياً دون حذف صفه فعلياً من التخزين؟
DeletedAtnullوقت تنفيذ الحذف الناعم إن طُبِّق؛ يبقى فارغاً ما دام السجل غير محذوف.
الحقول هنا، والتصفية في التخزين: هذا الملف يوفّر IsDeleted وDeletedAt فقط. استبعاد المحذوف يحدث في ApplicationDbContext عبر HasQueryFilter، لا داخل الكيان نفسه.

4) خلاصة تحفظها

  • BaseEntity صنف مجرد يجمع حقولاً مشتركة للكيانات الموروثة.
  • Id للمعرف، وCreatedAt / UpdatedAt لتتبع الزمن.
  • الحذف الناعم: IsDeleted وDeletedAt — إشارة في البيانات وليس حذفاً فيزيائياً في هذا الملف.
  • في هذا المشروع، Project يرث BaseEntity؛ أما ProjectTask فلا يرثه (راجع ملف المهمة).
