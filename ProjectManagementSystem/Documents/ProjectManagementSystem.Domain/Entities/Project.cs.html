شرح ملف Project.cs خطوة بخطوة

دليل للمبتدئ: كيف يُمثَّل المشروع في طبقة Domain؟ وما علاقته بالمهام وحالة ProjectStatus؟

قبل أن نبدأ: ما وظيفة هذا الملف؟

يُعرّف صنف Project: كيان يمثل مشروعاً في نظام إدارة المشاريع. يرث من BaseEntity فيحصل على المعرف والتواريخ والحذف الناعم، ويضيف اسماً ووصفاً وحالةً وتواريخ بدء واستحقاق، ومجموعة مهام مرتبطة.

Project ← يرث BaseEntity ← Status من ProjectStatus ← مجموعة Tasks

1) الاستيراد والإعلان عن الصنف

using ProjectManagementSystem.Domain.Enums;

namespace ProjectManagementSystem.Domain.Entities;

public class Project : BaseEntity
{
  • using ProjectManagementSystem.Domain.Enums: لاستخدام نوع ProjectStatus من ملف التعداد.
  • public class Project : BaseEntity: صنف عام قابل للإنشاء؛ الوراثة من BaseEntity تضيف الحقول المشتركة تلقائياً.

2) بيانات المشروع الأساسية

    public string Name { get; set; } = string.Empty;

    public string Description { get; set; } = string.Empty;

    public ProjectStatus Status { get; set; } = ProjectStatus.New;

    public DateTime StartDate { get; set; }

    public DateTime? DueDate { get; set; }
الخاصيةالنوع / الافتراضيالمعنى
Namestring = string.Emptyاسم المشروع؛ القيمة الابتدائية نص فارغ وليس null.
Descriptionstring = string.Emptyوصف المشروع؛ نفس نمط القيمة الافتراضية.
StatusProjectStatus.Newحالة المشروع كتعداد؛ عند إنشاء كائن جديد في الذاكرة تكون الحالة New (القيمة الرقمية 1 في التعداد).
StartDateDateTimeتاريخ البدء؛ لا يوجد في الملف قيمة افتراضية، فيجب تعيينها عند الاستخدام.
DueDateDateTime?تاريخ الاستحقاق اختياري؛ قد يكون null إذا لم يُحدَّد.

3) علاقة المهام (مجموعة التنقل)

    public ICollection<ProjectTask> Tasks { get; set; } = new List<ProjectTask>();
}
  • ICollection<ProjectTask>: واجهة تمثل مجموعة مهام تابعة للمشروع.
  • التهيئة بـ new List<ProjectTask>() تعني أن الخاصية ليست null عند إنشاء كائن Project جديد؛ يمكن الإضافة للقائمة مباشرة في الذاكرة.
  • هذه خاصية تنقل (navigation) نحو كيان ProjectTask؛ التحميل الفعلي من قاعدة البيانات لا يحدث في هذا الملف.
تنبيه: إذا طُبِّق الحذف الناعم على Project عبر IsDeleted من BaseEntity، قد تبقى كائنات ProjectTask مرتبطة في الذاكرة أو في التخزين حسب منطق الطبقات الأخرى — هذا الملف لا يحدد سلوك المهام عند حذف المشروع.

4) خلاصة تحفظها

  • Project يجمع بيانات المشروع ويرث التتبع الزمني والحذف الناعم من BaseEntity.
  • الحالة الافتراضية: ProjectStatus.New.
  • Tasks قائمة مهام مهيأة مسبقاً وغير فارغة من ناحية المرجع.
