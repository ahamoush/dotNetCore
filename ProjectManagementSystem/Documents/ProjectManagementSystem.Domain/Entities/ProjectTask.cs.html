شرح ملف ProjectTask.cs خطوة بخطوة

دليل للمبتدئ: كيف تُمثَّل مهمة داخل مشروع؟ وما الفرق بينها وبين Project وBaseEntity؟

قبل أن نبدأ: ما وظيفة هذا الملف؟

يُعرّف صنف ProjectTask: كيان مهمة مرتبطة بمشروع عبر ProjectId، مع عنوان ووصف وحالة إكمال وتاريخ استحقاق اختياري. الاسم ProjectTask يميّزه عن تضارب محتمل مع أنواع النظام الأخرى.

مهمة ← ProjectId (مفتاح أجنبي منطقي) ← Project? (تنقل اختياري) ← IsCompleted

1) الإعلان عن الصنف

namespace ProjectManagementSystem.Domain.Entities;

public class ProjectTask
{

لا يوجد using إضافي؛ الصنف لا يرث من BaseEntity ويُعرَّف كصنف مستقل داخل نفس مساحة أسماء الكيانات.

تنبيه تصميمي: على عكس Project، المهمة لا تحتوي على IsDeleted أو CreatedAt من BaseEntity. أي حذف ناعم أو تتبع زمني للمهام يجب أن يُنفَّذ في طبقة أخرى أو بحقول إضافية لاحقاً — وهذا الملف لا يوفّرها.

2) الهوية والمحتوى

    public int Id { get; set; }

    public string Title { get; set; } = string.Empty;

    public string Description { get; set; } = string.Empty;

    public bool IsCompleted { get; set; } = false;

    public DateTime? DueDate { get; set; }
الخاصيةملاحظة
Idمعرف المهمة (عدد صحيح).
Titleعنوان المهمة؛ افتراضياً نص فارغ.
Descriptionوصف تفصيلي؛ افتراضياً نص فارغ.
IsCompletedهل اكتملت المهمة؟ القيمة الافتراضية false.
DueDateموعد استحقاق اختياري (null مسموح).

3) الربط بالمشروع

    public int ProjectId { get; set; }

    public Project? Project { get; set; }
}
  • ProjectId: رقم يشير إلى المشروع المالك للمهمة (مفتاح علاقة على مستوى النموذج).
  • Project?: خاصية تنقل إلى كائن Project؛ علامة ? على النوع تعني أن المرجع قد يكون null إذا لم يُحمَّل المشروع أو لم يُربط بعد.
في الذاكرة يمكن أن يكون ProjectId صحيحاً بينما تبقى Project قيمتها null حتى تقوم طبقة التخزين بتحميل العلاقة (Eager/Lazy حسب الإعداد في Infrastructure — وليس في هذا الملف).
تنبيه: لا يتحقق هذا الملف من أن ProjectId يشير إلى مشروع موجود فعلاً؛ أي تحقق أو قيد سلامة يقع خارج طبقة Domain.

4) خلاصة تحفظها

  • ProjectTask كيان مستقل بدون وراثة من BaseEntity.
  • الإكمال يُعبَّر عنه بـ IsCompleted وليس بحالة تعداد مثل المشروع.
  • العلاقة مع المشروع: ProjectId + Project? للتنقل.
