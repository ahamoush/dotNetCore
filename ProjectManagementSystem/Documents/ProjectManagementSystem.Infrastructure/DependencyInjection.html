شرح ملف DependencyInjection.cs خطوة بخطوة

دليل للمبتدئ: كيف تُسجَّل قاعدة البيانات وIdentity والمستودعات والخدمات في حاوية DI.

قبل أن نبدأ: ما وظيفة هذا الملف؟

هذا الملف يوفّر الدالة الامتدادية AddInfrastructure التي يستدعيها Program.cs لتسجيل كل ما تحتاجه طبقة البنية التحتية: ApplicationDbContext مع SQL Server، وASP.NET Core Identity للمستخدمين والأدوار، ثم الـ Repositories والخدمات وتحويل الـ Claims.

ConnectionString ← DbContext ← Identity ← Repositories ← Auth & Admin ← ClaimsTransformation

1) توقيع الدالة والاتصال بقاعدة البيانات

public static IServiceCollection AddInfrastructure(
    this IServiceCollection services,
    IConfiguration configuration)
{
    services.AddDbContext<ApplicationDbContext>(options =>
        options.UseSqlServer(configuration.GetConnectionString("DefaultConnection")));
الجزءالمعنى
GetConnectionString("DefaultConnection")يقرأ سلسلة الاتصال من الإعدادات تحت المفتاح ConnectionStrings:DefaultConnection — لا تُخزَّن القيمة السرية في هذا الشرح.
AddDbContext<ApplicationDbContext>يسجّل سياق EF Core بحيث يُحقَن في المستودعات وUserAdminService.
UseSqlServerيحدد مزود SQL Server (الحزمة Microsoft.EntityFrameworkCore.SqlServer).

2) إعداد Identity Core

services
    .AddIdentityCore<ApplicationUser>(options =>
    {
        options.User.RequireUniqueEmail = true;
        options.Password.RequiredLength = 8;
        options.Password.RequireDigit = true;
        options.Password.RequireUppercase = true;
        options.Password.RequireLowercase = true;
        options.Password.RequireNonAlphanumeric = false;
    })
    .AddRoles<IdentityRole>()
    .AddEntityFrameworkStores<ApplicationDbContext>();
خيار كلمة المرور / المستخدمالقيمة في الكود
بريد فريدRequireUniqueEmail = true
الحد الأدنى للطول8 أحرف
رقم، حرف كبير، حرف صغيرمطلوب
رمز غير أبجدي رقميغير مطلوب (false)
ملاحظة: AddIdentityCore يوفّر UserManager وRoleManager بدون واجهات تسجيل الدخول الكاملة؛ JWT يُدار في مشروع الـ API وAuthService.

3) تسجيل المستودعات والخدمات

services.AddScoped<IProjectRepository, ProjectRepository>();
services.AddScoped<ITaskRepository, TaskRepository>();
services.AddScoped<IAuthService, AuthService>();
services.AddScoped<IUserAdminService, UserAdminService>();
services.AddTransient<IClaimsTransformation, PermissionClaimsTransformation>();
الواجهةالتنفيذدورة الحياة
IProjectRepositoryProjectRepositoryScoped (طلب HTTP واحد)
ITaskRepositoryTaskRepositoryScoped
IAuthServiceAuthServiceScoped
IUserAdminServiceUserAdminServiceScoped
IClaimsTransformationPermissionClaimsTransformationTransient

ملخص

ملف واحد يربط الإعدادات بقاعدة البيانات، يفعّل Identity على ApplicationUser، ويسجّل كل تنفيذات طبقة Infrastructure التي تستهلكها طبقة Application والـ API.
