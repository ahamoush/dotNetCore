3) Project — فلاتر وحذف ناعم

entity.HasQueryFilter(p => !p.IsDeleted);
entity.Property(p => p.Status)
    .HasDefaultValue(ProjectStatus.New)
    .HasSentinel((ProjectStatus)0);
entity.HasMany(p => p.Tasks)
    .WithOne(t => t.Project)
    .HasForeignKey(t => t.ProjectId)
    .OnDelete(DeleteBehavior.Cascade);
إعدادالمعنى
HasQueryFilterأي استعلام عادي يستبعد IsDeleted == true
الاسم / الوصفحد أقصى 100 / 500، مطلوبان
IsDeletedافتراضي false
حذف المشروعCascade على مهامه
تنبيه: لرؤية مشروع محذوف في استعلام خاص استخدم IgnoreQueryFilters() — غير مستخدم في المستودعات الحالية.

4) ProjectTask

entity.HasQueryFilter(t => !t.Project!.IsDeleted);
entity.Property(t => t.Title).HasMaxLength(150).IsRequired();
entity.Property(t => t.Description).HasMaxLength(1000).IsRequired();
مهام المشاريع «المحذوفة منطقياً» تختفي أيضاً لأن الفلتر يعتمد على Project.IsDeleted.
