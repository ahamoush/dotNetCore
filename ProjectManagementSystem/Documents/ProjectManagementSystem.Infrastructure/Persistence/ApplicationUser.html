شرح ملف ApplicationUser.cs خطوة بخطوة

نوع المستخدم المخصص لـ Identity في المشروع.

قبل أن نبدأ: ما وظيفة هذا الملف؟

يمتد IdentityUser ويضيف حقلاً واحداً للتطبيق: الاسم الكامل المعروض في JWT وواجهات الإدارة.

الكود

public class ApplicationUser : IdentityUser
{
    public string FullName { get; set; } = string.Empty;
}
من IdentityUser (موروث)استخدام شائع في المشروع
Id, Email, UserNameclaim sub والبريد في AuthService
PasswordHashلا يُعرض أبداً للعميل
EmailConfirmedيُضبط true لـ SuperAdmin في الـ Seeder

في قاعدة البيانات العمود FullName يُخزَّن في جدول AspNetUsers بطول 100 (من ApplicationDbContext).

ملخص

كلاس صغير لكنه نقطة ربط Identity ببيانات التطبيق؛ يُسجَّل في AddIdentityCore<ApplicationUser>.
