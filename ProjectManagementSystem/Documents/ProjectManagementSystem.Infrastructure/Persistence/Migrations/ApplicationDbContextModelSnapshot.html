شرح ملف ApplicationDbContextModelSnapshot.cs خطوة بخطوة

لقطة حالة نموذج EF الحالية — يُحدَّث عند كل ترحيل جديد.

قبل أن نبدأ: ما وظيفة هذا الملف؟

صنف ApplicationDbContextModelSnapshot يرث ModelSnapshot. EF يقارن بين هذا الملف وبين نموذج ApplicationDbContext الحالي لمعرفة ما إذا كان ترحيلاً جديداً مطلوباً.

مُولَّد تلقائياً — لا تحرير يدوي. الحجم كبير (مئات الأسطر من modelBuilder.Entity).

1) بنية الملف (مقتطف)

// <auto-generated />
[DbContext(typeof(ApplicationDbContext))]
partial class ApplicationDbContextModelSnapshot : ModelSnapshot
{
    protected override void BuildModel(ModelBuilder modelBuilder)
    {
        modelBuilder.HasAnnotation("ProductVersion", "10.0.14");
        SqlServerModelBuilderExtensions.UseIdentityColumns(modelBuilder);
        // تعريف كل كيان وجدول وفهارس وعلاقات
    }
}

2) ملخص الجداول في اللقطة الحالية

مع وجود ترحيل InitialCreate فقط، اللقطة تصف نفس المجموعة التالية:

الكيانالجدول
IdentityRole + claims/logins/roles/tokensAspNetRoles, AspNetRoleClaims, AspNetUserClaims, AspNetUserLogins, AspNetUserRoles, AspNetUserTokens
ApplicationUserAspNetUsers
ProjectProjects
ProjectTaskTasks
يضم الملف أيضاً تفاصيل الأعمدة، القيم الافتراضية، الفهارس، سلوك الحذف، وفلاتر الاستعلام العامة (query filters) المطابقة لـ OnModelCreating — مثل استبعاد المشاريع المحذوفة منطقياً.
