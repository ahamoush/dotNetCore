شرح ملف AuthService.cs خطوة بخطوة

تسجيل مستخدم جديد، تسجيل الدخول، وإنشاء JWT مع الأدوار والصلاحيات في الاستجابة.

قبل أن نبدأ: ما وظيفة هذا الملف؟

ينفّذ IAuthService: يستخدم UserManager<ApplicationUser> لإنشاء المستخدمين والتحقق من كلمات المرور، ثم يبني AuthResponseDto يتضمن توكن JWT وقائمة الصلاحيات المشتقة من الأدوار عبر RolePermissionMap.

Register ← دور Member ← Login ← Claims ← JWT

1) التسجيل — RegisterAsync

var user = new ApplicationUser
{
    UserName = dto.Email,
    Email = dto.Email,
    FullName = dto.FullName
};
var create = await _users.CreateAsync(user, dto.Password);
// ...
var addRole = await _users.AddToRoleAsync(user, AppRoles.Member);
الخطوةالنتيجة عند الفشل
إنشاء المستخدم بكلمة المرور من الـ DTOAuthResult.Failure مع رسائل Identity
إضافة دور AppRoles.Memberنفس النمط
نجاحCreateResponseAsync → توكن + بيانات المستخدم

2) تسجيل الدخول — LoginAsync

var user = await _users.FindByEmailAsync(dto.Email);
if (user is null || !await _users.CheckPasswordAsync(user, dto.Password))
    return AuthResult.Failure("Invalid email or password.");
لا يُفرَّق رسالة الخطأ بين «البريد غير موجود» و«كلمة المرور خاطئة» — نفس النص لأسباب أمنية.

3) إنشاء التوكن — Claims وإعدادات Jwt

var claims = new List<Claim>
{
    new Claim(JwtRegisteredClaimNames.Sub, user.Id),
    new Claim(JwtRegisteredClaimNames.Email, user.Email ?? string.Empty),
    new Claim(AppClaimTypes.Name, user.FullName)
};
foreach (string role in roles)
    claims.Add(new Claim(AppClaimTypes.Role, role));
مفتاح الإعداداتالاستخدام في الكود
Jwt:Issuerمُصدِر التوكن
Jwt:Audienceالجمهور المتوقع
Jwt:Keyمفتاح HMAC (يُقرأ عبر ReadKey() — يجب أن يكون طوله ≥ 32 حرفاً؛ القيمة تبقى في الإعدادات فقط)
Jwt:ExpiresInMinutesمدة الصلاحية بالدقائق؛ إن لم تُعرَف أو ≤ 0 يُستخدم 60
var token = new JwtSecurityToken(
    issuer: _configuration["Jwt:Issuer"],
    audience: _configuration["Jwt:Audience"],
    claims: claims,
    expires: expiresAt,
    signingCredentials: credentials);

الصلاحيات Permissions تُملأ في AuthResponseDto من RolePermissionMap.ForRoles(roles) ولا تُضاف كـ Claims داخل التوكن في هذا الملف.

تنبيه: لا تنسخ قيمة Jwt:Key أو كلمات مرور إلى التوثيق أو المستودع العام.

ملخص

AuthService هو الجسر بين Identity وJWT: عضو جديد يحصل على دور Member، والاستجابة تحمل التوكن والأدوار وقائمة الصلاحيات المحسوبة للواجهة أو العميل.
