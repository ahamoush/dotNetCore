# شرح TasksController.cs

باب المهام. المسار `api/tasks`. الكلاس يطلب توكناً.

المنشئ: الخدمة، وValidator الإنشاء، وValidator التعديل.

- `GET api/tasks` أو `?projectId=3`. صلاحية مشاهدة المهام. `projectId` اختياري.
- `GET api/tasks/5` واحدة أو 404.
- `POST` يتحقق ثم ينشئ. إذا رجعت الخدمة `null` فالمشروع غير موجود ونرد 400 برسالة واضحة. هذا ليس فشل Validator. الرقم صحيح لكن الصف غير موجود.
- `PUT api/tasks/5` تحقق ثم تعديل. 404 إذا غابت المهمة. 204 عند النجاح.
- `DELETE` حذف حقيقي. 404 أو 204.
