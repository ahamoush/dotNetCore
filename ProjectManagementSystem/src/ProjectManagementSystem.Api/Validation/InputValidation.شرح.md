# شرح InputValidation.cs

دالة واحدة ظاهرة بدل فلتر يستخدم الانعكاس. الكونترولر يستدعيها بنفسه، فترى التحقق في أعلى كل عملية.

`CheckAsync<T>` تعمل مع أي نوع. `T` هو نوع الـ DTO.

1. `ValidateAsync` يشغّل قواعد FluentValidation.
2. إذا `IsValid` ترجع `null`. عند الكونترولر `null` تعني "أكمل العمل".
3. إذا لا، تبني قاموساً: اسم الخاصية ثم قائمة رسائلها. الخاصية قد تفشل بأكثر من قاعدة، مثل كلمة السر.
4. `TryGetValue` إن لم يوجد المفتاح ينشئ قائمة جديدة.
5. `ValidationProblemDetails` شكل خطأ 400 القياسي.
6. كل قائمة تتحول إلى مصفوفة وتوضع في `Errors`.
7. الحالة 400 والعنوان الثابت.
8. `BadRequestObjectResult` هو الرد. الكونترولر يكتبه `return invalid`.
