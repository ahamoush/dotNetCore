# شرح SetUserRolesDto.cs

جسم `PUT /api/users/{id}/roles`.

- `Roles` قائمة الأسماء المطلوبة بعد التعديل، ليست الأسماء المضافة فقط.
  مثال: `["Admin","Viewer"]` يعني هذان الدوران فقط. أي دور قديم غير موجود في القائمة يُزال.

القائمة تبدأ بـ `[]` حتى لا تكون `null` إذا وصل JSON بدون الحقل. الـ Validator يرفض القائمة الفارغة.
