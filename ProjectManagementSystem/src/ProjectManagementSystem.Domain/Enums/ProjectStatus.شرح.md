# شرح ProjectStatus.cs

قائمة مغلقة بحالات المشروع. لا يجوز كتابة حالة من خارج هذه القائمة.

## الأسطر

- `public enum ProjectStatus`
  تعداد. كل اسم داخله رقم ثابت.

- `New = 1`
  جديد. الرقم يبدأ من 1 وليس 0 حتى لا تختلط القيمة الفارغة `0` مع حالة حقيقية.

- `InProgress = 2`
  قيد العمل.

- `Completed = 3`
  مكتمل.

- `OnHold = 4`
  متوقف مؤقتاً.

- `Cancelled = 5`
  ملغى.

الأرقام تُحفظ في عمود SQL. لو غيّرت رقماً بعد نشر قاعدة البيانات، الصفوف القديمة ستُقرأ بمعنى آخر. لا تغيّر الأرقام بعد أول ترحيل.
