Engineering brief

Project Management System

واجهة ويب واحدة تحفظ المشاريع ومهامها في SQL Server. الطلب يدخل من المتحكم، يمر بالخدمة، ثم يكتب أو يقرأ عبر ApplicationDbContext.

C# ASP.NET Core net10.0 EF Core SQL Server Swagger

هرمية الطلب

عميل — متصفح أو Swagger أو أي عميل HTTP على http://localhost:5149
مدخل — Program.cs يبني الخدمات وخط الأنابيب
حماية — Middleware/ExceptionHandlingMiddleware.cs يلتقط الاستثناء غير المتوقع ويرد 500
عرض — Controllers/ProjectsController.cs وControllers/TasksController.cs
عقد — Interfaces/IProjectService.cs وInterfaces/ITaskService.cs
تطبيق — Services/ProjectService.cs وServices/TaskService.cs
بيانات — Data/ApplicationDbContext.cs ثم جداول Projects وTasks

أقسام الشرح

نظرة عامة

ماذا يفعل النظام، حدوده، ومن يستدعيه.

العمارة

اتجاه الاعتماد ومن يتحدث مع من.

الوحدات

كل مجلد: لماذا يوجد وماذا يستقبل.

نموذج البيانات

المشروع، المهمة، الحذف الناعم، والعلاقة 1 إلى كثير.

الواجهات البرمجية

كل مسار HTTP: المدخل والمخرج وملف المصدر.

التدفقات

إنشاء مشروع، بحث مرقّم، حذف، ومسار الخطأ.

الشاشات

لا واجهة مستخدم. Swagger هو الشاشة الوحيدة.

التشغيل

كيف يُشغَّل محلياً وأسماء مفاتيح الإعداد.

المصطلحات

المصطلحات كما هي مستخدمة في هذا المستودع.

تشغيل محلي

cd ProjectManagementSystem
dotnet run --launch-profile http

الملف التعريفي http يستمع على http://localhost:5149. واجهة Swagger على /swagger وتُفعَّل فقط عندما تكون البيئة Development.
