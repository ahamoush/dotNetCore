Engineering brief

التدفقات

ستة مسارات موجودة في الكود: إنشاء مشروع، قائمة مرقّمة، حذف ناعم، إنشاء مهمة، حذف مهمة، واستثناء غير متوقع.

1. إنشاء مشروع

المُطلِق: POST /api/Projects بجسم اسم ووصف صالحين.

عميل← ProjectsController.Create← ProjectService.CreateAsync← Projects.Add← SaveChangesAsync← 201
  1. المتحكم يمرر CreateProjectDto إلى IProjectService.CreateAsync.
  2. الخدمة تبني Project بالاسم والوصف فقط. الحالة تبقى القيمة الابتدائية New.
  3. SaveChangesAsync في السياق يضع CreatedAt لأن الحالة Added.
  4. المتحكم يرجع 201 عبر CreatedAtAction(GetById) مع DTO فيه المعرّف والاسم والوصف والحالة ووقت الإنشاء.

مسار الفشل: اسم أقصر من 3 أو أطول من 100، أو وصف أطول من 500، يرفضه تحقق النموذج قبل الخدمة.

2. قائمة المشاريع المرقّمة

المُطلِق: GET /api/Projects مع استعلام.

عميل← فحص الصفحة والحجم← بحث ثم حالة ثم ترتيب← Count ثم Skip/Take← PagedResultDto
  1. إذا PageNumber < 1 أو PageSize خارج 1–100 يرجع المتحكم 400 Invalid pagination parameters.
  2. GetProjectsAsync يبدأ من Projects.AsNoTracking. مرشح الحذف الناعم مطبَّق، فالمشاريع المحذوفة لا تدخل.
  3. إن وُجد Search يُقص ويُطابَق داخل Name أو Description.
  4. إن وُجد Status تُصفّى المساواة.
  5. SortBy بعد التصغير: createdat أو duedate، وغيرهما يرتّب بالاسم. Descending يعكس الاتجاه.
  6. يُحسب العدد الكلي ثم تُؤخذ الصفحة وتُحوَّل إلى ProjectResponseDto.

مسار فارغ: لا صفوف مطابقة تُرجع 200 مع Items فارغة وTotalCount = 0. لا 404.

3. حذف مشروع

المُطلِق: DELETE /api/Projects/{id}.

عميل← DeleteAsync← IsDeleted و DeletedAt← 204
  1. الخدمة تبحث بالمعرّف. مرشح الاستعلام يتجاهل المحذوف سلفاً، فتكرار الحذف يرجع false ثم 404.
  2. إن وُجد الصف: IsDeleted = true وDeletedAt = DateTime.UtcNow ثم حفظ. لا Remove.
  3. بعدها تختفي المهام التابعة من استعلامات TaskService بسبب مرشح !t.Project!.IsDeleted.

4. إنشاء مهمة

المُطلِق: POST /api/Tasks.

عميل← TasksController.Create← Projects.AnyAsync← Tasks.Add← 201 أو 400
  1. الخدمة تتحقق أن ProjectId يطابق مشروعاً غير محذوف.
  2. إذا لا يوجد مشروع ترجع null والمتحكم يرد 400 Project does not exist.
  3. إذا وُجد تُنشأ ProjectTask بالعنوان والوصف وتاريخ الاستحقاق ومعرّف المشروع. IsCompleted يبقى false.
  4. المهمة لا ترث BaseEntity، لذلك SaveChangesAsync لا يكتب لها وقت إنشاء.

5. حذف مهمة

المُطلِق: DELETE /api/Tasks/{id}.

عميل← FindAsync← Remove← 204
  1. FindAsync يحمّل المهمة. إن غابت أو كانت تابعة لمشروع محذوف (المرشح) ترجع الخدمة false ثم 404.
  2. إن وُجدت يُحذف الصف من الجدول Tasks. هذا حذف فعلي، بخلاف المشروع.

6. استثناء غير متوقع

المُطلِق: أي استثناء يفلت من الفعل، مثل فشل الاتصال بقاعدة البيانات.

طلب← ExceptionHandlingMiddleware← LogError← 500 JSON
  1. الوسيط يستدعي _next داخل try.
  2. يسجّل Unexpected error occurred.
  3. إن لم يبدأ الرد: يمسحه، يضع 500 وapplication/json، ويكتب رسالة عامة بلا تفاصيل الاستثناء.
من الكود لا مسار تسجيل دخول. 401 و403 غير مُنتَجين في المتحكمات.
