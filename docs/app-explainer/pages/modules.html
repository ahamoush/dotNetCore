Engineering brief

الوحدات

كل مجلد تحت ProjectManagementSystem وحدة واحدة. لا سياقات أعمال منفصلة سوى المشروع والمهمة.

Controllers

المسار Controllers/. يستقبل HTTP ويتحقق من شكل بعض المدخلات ثم يترجم نتيجة الخدمة إلى رمز حالة.

النوع العاميعتمد علىلا يعتمد على
ProjectsControllerIProjectServiceDbContext، كيانات
TasksControllerITaskServiceDbContext، كيانات

المسار الأساسي api/[controller] فيصبح api/Projects وapi/Tasks.

Interfaces

المسار Interfaces/. عقد الاستدعاء الذي يسجله Program.cs.

  • IProjectService: قراءة الكل، قراءة بالمعرّف، إنشاء، تعديل، حذف، وقائمة مرقّمة.
  • ITaskService: قراءة مع تصفية اختيارية بـ projectId، قراءة بالمعرّف، إنشاء، تعديل، حذف.

Services

المسار Services/. مكان قواعد القراءة والكتابة.

الصنفلماذا يوجديخرج إلى
ProjectService بحث بالاسم أو الوصف، تصفية بالحالة، ترتيب، ترقيم، وحذف ناعم ApplicationDbContext.Projects
TaskService مهام مشروع، والتحقق أن المشروع موجود قبل الإنشاء، وحذف فعلي Tasks وProjects
من الكود استعلامات القراءة في الخدمتين تستخدم AsNoTracking ثم Select إلى DTO. التعديل والحذف يحمّلان الكيان ثم يحفظان.

DTOs

المسار DTOs/. شكل الطلب والاستجابة. التحقق بـ Data Annotations على الإنشاء والتعديل.

الملفالحقول التي تهم
Projects/CreateProjectDto.csName مطلوب 3–100، Description حتى 500
Projects/UpdateProjectDto.csنفس حقول الإنشاء. لا حالة ولا تواريخ
Projects/ProjectResponseDto.csId، Name، Description، Status، CreatedAt
Tasks/CreateTaskDto.csTitle 3–150، Description حتى 1000، DueDate، ProjectId من 1
Tasks/UpdateTaskDto.csالعنوان والوصف والإكمال وتاريخ الاستحقاق. لا ProjectId
Tasks/TaskResponseDto.csId، العنوان، الوصف، IsCompleted، DueDate، ProjectId
ProjectQueryDto.csSearch، Status، PageNumber=1، PageSize=10، SortBy=Name، Descending
PagedResultDto.csItems، TotalCount، PageNumber، PageSize، وTotalPages محسوب
من الكود ProjectQueryDto وPagedResultDto وProjectStatus وBaseEntity بلا فضاء أسماء. بقية الأنواع تحت ProjectManagementSystem.*.

Models

المسار Models/. الكيانات التي يترجمها EF.

  • BaseEntity: Id، CreatedAt، UpdatedAt، IsDeleted، DeletedAt.
  • Project يرث BaseEntity ويضيف الاسم والوصف والحالة وتاريخي البداية والاستحقاق ومجموعة المهام.
  • ProjectTask لا يرث BaseEntity. مفتاح أجنبي ProjectId.
  • ProjectStatus: New=1، InProgress=2، Completed=3، OnHold=4، Cancelled=5.
من الكود أعلى Project.cs تعريف قديم معلّق بالكامل. النوع الحي هو public class Project : BaseEntity.

Data

Data/ApplicationDbContext.cs يعرّف DbSet<Project> Projects وDbSet<ProjectTask> Tasks. يضبط أطوال الحقول، القيمة الافتراضية للحالة، مرشح الاستعلام، وعلاقة الحذف المتتالي. SaveChangesAsync يكتب وقت الإنشاء أو التعديل لكيانات BaseEntity فقط.

Middleware و Exceptions

ExceptionHandlingMiddleware يغلّف بقية الأنبوب. عند استثناء لم يبدأ الرد بعده يمسح الاستجابة ويرسل {"statusCode":500,"message":"An unexpected error occurred."} ويسجّل الخطأ.

غير مستخدم Exceptions/NotFoundException.cs فارغ. غياب السجل يُعاد اليوم كـ null أو false من الخدمة، والمتحكم يحوّلها إلى 404.
