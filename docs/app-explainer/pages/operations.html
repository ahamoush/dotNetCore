Engineering brief

التشغيل

التشغيل المحلي أمر dotnet run من مجلد المشروع. لا Docker ولا فحص صحة ولا عامل خلفية في المستودع.

تشغيل محلي

من Properties/launchSettings.json:

ملف التعريفالعنوانالبيئة
httphttp://localhost:5149Development
httpshttps://localhost:7187 وhttp://localhost:5149Development
 
cd ProjectManagementSystem
dotnet run --launch-profile http

Swagger بعد الإقلاع: http://localhost:5149/swagger.

من الكود ملف التعريف http لا يعرّف منفذ HTTPS. عندها يسجّل HttpsRedirectionMiddleware تحذيراً: فشل تحديد منفذ HTTPS لإعادة التوجيه. الاستماع على 5149 يبقى قائماً.

المصادقة

لا Cookie ولا JWT ولا Windows auth في التكوين. الوسيط UseAuthorization موجود بلا مخطط.

السجلات

مزود السجل الافتراضي للإطار. الكتابة الصريحة الوحيدة في التطبيق هي LogError داخل ExceptionHandlingMiddleware عند استثناء غير متوقع. لا Serilog ولا ملف سجل مخصص.

الصحة والنشر

لا MapHealthChecks، ولا Dockerfile، ولا سكربت نشر في المستودع. تطبيق الهجرات موجود كملفات C# تحت Migrations/؛ لا أمر ترحيل تلقائي داخل Program.cs (لا Database.Migrate).

استنتاج قاعدة البيانات تُحدَّث بأمر خارجي مثل dotnet ef database update، لأن الإقلاع لا يطبّق الهجرات بنفسه. الأمر نفسه غير موثّق داخل المستودع.

حزم ذات تحذير

من الكود بناء المشروع يُظهر تحذيري NU1902 وNU1903 على الحزمة العابرة System.Security.Cryptography.Pkcs 9.0.11. المشروع لا يشير إليها مباشرة في csproj.
